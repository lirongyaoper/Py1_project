## 使用建议

### 新手用户
推荐使用 `dicom_niigz.py` (改进的原始版本):
- 简单易懂
- 基本错误处理
- 适合快速转换任务

### 高级用户
推荐使用 `dicom_niigz_optimized.py`:
- 完整的面向对象设计
- 详细的日志记录
- 更强的错误处理能力
- 适合生产环境

### 批量处理
使用 `example_usage.py` 中的示例:
- 多数据集批量处理
- 自定义配置支持
- nnU-Net工作流集成

## 环境要求总结

- **Python环境**: conda nnunet (Python 3.7+)
- **核心依赖**: dcm2niix工具
- **系统要求**: Linux/macOS/Windows WSL2
- **内存建议**: 8GB+ RAM
- **存储建议**: SSD存储以提高性能

## 快速开始

1. **环境准备**:
   ```bash
   conda activate nnunet
   conda install -c conda-forge dcm2niix
   ```

2. **基本使用**:
   ```bash
   python dicom_niigz.py /path/to/dicom /path/to/output
   ```

3. **高级使用**:
   ```bash
   python example_usage.py
   ```
