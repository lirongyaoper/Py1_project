# DICOM到NIfTI转换工具说明文档

## 概述

这是一个用于批量将DICOM格式的医学影像文件转换为NIfTI格式（.nii.gz）的Python脚本。该工具主要用于医学影像数据的格式转换，便于后续的影像分析和处理。

## 功能描述

### 主要功能
- **批量转换**: 自动遍历指定源目录下的所有子文件夹
- **格式转换**: 将DICOM（.dcm）格式转换为压缩的NIfTI格式（.nii.gz）
- **目录结构保持**: 在目标目录中创建与源目录相同的文件夹结构
- **进度显示**: 实时显示转换进度和完成百分比

### 转换流程
1. 检查并创建目标目录（如果不存在）
2. 获取源目录下所有子文件夹列表
3. 逐个遍历每个子文件夹：
   - 在目标目录创建对应的文件夹
   - 调用`dcm2niix`工具进行格式转换
   - 显示当前转换进度

## 技术实现

### 核心函数：`dcm_niigz(source_path, dest_dir)`

**参数：**
- `source_path`: 源目录路径，包含待转换的DICOM文件夹
- `dest_dir`: 目标目录路径，存放转换后的NIfTI文件

**转换命令：**
```bash
dcm2niix -o {目标文件夹}/ -z y {源文件夹}
```

**参数说明：**
- `-o`: 指定输出目录
- `-z y`: 启用gzip压缩，生成.nii.gz文件
- 最后的路径参数是要转换的DICOM文件夹

## 注意事项

1. **权限要求**: 确保对源目录有读取权限，对目标目录有写入权限
2. **存储空间**: NIfTI文件可能比原DICOM文件更大，确保有足够存储空间
3. **工具依赖**: 必须先安装dcm2niix工具
4. **数据备份**: 建议在转换前备份原始DICOM数据
5. **路径格式**: 使用绝对路径以避免路径错误
